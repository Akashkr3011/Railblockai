# RAILBLOCK AI — Simulation Engine

⚠️ All simulation data is CLEARLY LABELED as SIMULATED.
It does NOT represent actual Indian Railways live operations.

## Planned Components (future stages)

### Train Schedule Simulator (MOCK TMS)
- Simulates train movement on sections
- Generates synthetic block conflicts
- Labeled: [SIMULATED TMS]

### COA Replay Engine (SIMULATED COA)
- Replays historical Chief Operating Analyst reports
- Supports what-if scenario evaluation
- Labeled: [SIMULATED COA]

### Block Utilization Simulator
- Generates realistic block utilization patterns
- Based on Indian Railways track maintenance norms
- Labeled: [SIMULATION]

## Data Notice
No real-time Indian Railways data is used.
The architecture is ready for integration with authorized data sources.
